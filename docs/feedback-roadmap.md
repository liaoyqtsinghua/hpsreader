# HPS Reader 反馈处理排期

本文档把 `docs/feedback.md` 中的实际使用反馈转为开发排期。排期原则：先处理阻塞性缺陷和高频研读闭环，再处理需要底层依赖或架构改造的能力。

## Sprint A：当前优先落地

状态：基础修复已完成，进入使用复测。

目标：解决真实使用中最影响连续工作的四类问题。

- F-001 批量生成翻译
  - 已完成：前端保留“批量翻译”入口，并支持全部未译段落、起始页 + 页数、从当前段落到文档末尾。
  - 已完成：后端新增批量翻译 job，逐段调用当前 LLM Provider、逐段保存译文、逐段记录认知足迹。
  - 已完成：前端按 job 轮询进度，显示成功、跳过、失败、当前段落。
  - 后续增强：任务持久化、暂停/恢复、失败重试、并发限流。
- F-013 术语修正与词形变化
  - 已完成：术语库支持 `variants[]`、`lemma`、`language`。
  - 已完成：术语匹配支持大小写不敏感、重音弱匹配、连字符/空格变化、简单复数变体。
  - 已完成：术语修正改为可确认/可编辑建议，不再静默追加译法。
  - 后续增强：接入 lemmatizer / stemmer / morphological analyzer，按语言提供更精确的词形分析。
- F-014 原文/译文 comment 与 LLM 辅助
  - 已完成：段落新增 `comments[]` 数据结构。
  - 已完成：原文和译文都可基于选中文本添加批注。
  - 已完成：批注弹窗可调用当前 LLM Provider 生成批注草稿。
  - 已完成：批注保存后显示在段落下方，并支持删除。
  - 后续增强：行内高亮锚点、批注编辑历史、批注导出专项选项。
- F-012 原图/文件默认预览而非下载
  - 已完成：source 接口默认 `Content-Disposition: inline`。
  - 已完成：新增明确下载接口。
  - 已完成：前端打开预览窗口，顶部提供下载按钮。
  - 后续增强：PDF 页码精确跳转、页面截图预览、多模态页图处理。

## Sprint B：OCR 与原文版面保真

状态：基础修复已完成，重依赖能力进入后续增强。

目标：解决复杂 PDF、扫描件和原文版面丢失问题。

- F-003 OCR 后丢失原文图片上下文
  - 已完成基础：文档保留原始文件路径，段落包含 `pageIndex`，可打开原文文件。
  - 已完成：右侧“原文页图”面板使用浏览器 PDF.js 渲染当前 PDF 页，便于对照原始版面。
  - 待处理：生成每页截图或页面图像，保存 `pages[].imagePath`。
  - 待处理：段落绑定 bbox、OCR 置信度、页面坐标。
  - 待处理：多模态模型基于页图进行解释、校对或结构化识别。
- F-007 OCR 乱码、字体适配与开源 OCR 方案
  - 已完成基础：标记 `extractionMethod`，检测 PDF text layer 乱码风险。
  - 已完成：接入 `tesseract.js` 本地开源 OCR Provider，图片文件可直接 OCR 并写回段落。
  - 已完成：PDF 可由前端 PDF.js 渲染当前页图，再上传页图给后端 Tesseract.js OCR。
  - 已完成：新增 OCR Provider 列表、文档 OCR 状态接口、OCR 文本规范化。
  - 待处理：PDF 乱码严重时自动批量 fallback 到页面图像 OCR。
  - 待处理：接入 PaddleOCR/Tesseract CLI 或服务端渲染插件，解决大批量 PDF 页图生成。
  - 待处理：按拉丁文、希腊文、法文、德文、中文做更精确的语言适配。

## Sprint C：产出、Agent 与 UI 复测

状态：Sprint C 基础优化已完成，进入使用复测。

- F-011 导入/导出/保存选项
  - 已完成基础：导入项目备份、导出 modal、JSON/Markdown/TXT/CSV/TSV、多内容方案和范围。
  - 已完成：导出新增批注、译文 + 批注方案；表格导出增加 comments 列。
  - 已完成：保存按钮改为“保存项目快照”，后端保留最近 12 个项目快照并记录存储事件。
  - 待处理：DOCX/PDF 导出，需要新增文档渲染依赖。
  - 待处理：快照恢复/对比界面、整项目导出范围、DOCX/PDF 渲染。
- F-004 / F-005 / F-015 Agent 体验
  - 已完成基础：中文 Agent 名称、原语言学习 Agent、DeepSeek/OpenAI-compatible runtime、细化 Prompt 模板。
  - 已完成：前端显示当前 Provider 是否支持工具 Agent；不支持的 Provider 会在运行前提示。
  - 已完成：修复 OpenAI-compatible 工具 schema 重复转换问题，DeepSeek / Qwen / OpenRouter / 本地 OpenAI-compatible Provider 可直接进入 Agent runtime。
  - 已完成：补充“对比原图与 OCR 文本”“生成论文式批注”等更具体的 Prompt 模板。
  - 待复测：DeepSeek tool calling 实际稳定性取决于所选模型；Gemini 暂不支持工具 Agent。
- F-006 UI 淡紫极简
  - 已完成基础：主题变量、轻量边框、淡紫色系。
  - 已完成：Agent Provider 状态、术语标注开关等新增控件使用同一套淡紫极简样式。
  - 待复测：长文档密度、批注列表、批量翻译弹窗和原文件预览窗口的视觉一致性。
- F-008 / F-009 / F-010 阅读导航、浮动笔记、术语标注
  - 已完成基础：页码跳转/锁定、浮动笔记、术语高亮。
  - 已完成：锁定页会联动右侧 PDF 页图预览，未锁定时切换段落会尝试跟随当前页。
  - 已完成：浮动笔记拖拽位置写入本地存储，重新打开时恢复位置。
  - 已完成：Workbench 增加术语标注开关，支持关闭/开启原文术语高亮。
  - 待处理：术语权重、自适应推荐、只显示当前页术语。
